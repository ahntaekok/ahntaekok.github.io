# 이미지 가이드

이 폴더에 프로젝트 스크린샷과 다이어그램을 넣으세요.

`src/data/projects.json` 의 `images[].src` 가 참조하는 파일명과 동일하게 저장하면 됩니다. 파일이 없으면 자동으로 🖼️ placeholder 가 표시됩니다.

## 필요한 이미지 파일 목록

### 1. 라온픽 (LAONPICK)
- `raonpick-hero.png` — 실행 프로그램(.exe) 메인 UI 캡처
- `raonpick-arch.png` — 시스템 아키텍처 다이어그램

### 2. 애드핀 (ADPIN)
- `adpin-dashboard.png` — sany.raonpick.pro 메인 대시보드
- `adpin-arch.png` — 2-Tier 아키텍처 다이어그램
- `adpin-rank-chart.png` — 플레이스 순위 추적 차트

### 3. 스마트 HACCP
- `haccp-cert.png` — 스마트 HACCP 공식 인증서
- `haccp-dashboard.png` — CCP 실시간 모니터링 대시보드

### 4. 동주산업 MES
- `mes-dashboard.png` — MES 실시간 공정 현황 대시보드
- `mes-erd.png` — 직접 설계한 ERD

### 5. Homepad
- `homepad-result.png` — AI 자동 생성된 홈페이지 결과물

## 권장 사이즈
- 16:9 비율 (예: 1280 × 720 px)
- 파일 크기: 200KB 이내 권장 (TinyPNG 등으로 압축)

## 추천 도구
- 캡처: macOS `⌘⇧4` 또는 [CleanShot X](https://cleanshot.com)
- 목업 프레임: [mockuuups.studio](https://mockuuups.studio), [shots.so](https://shots.so)
- 아키텍처 다이어그램: [excalidraw.com](https://excalidraw.com) 또는 [draw.io](https://draw.io)
- 이미지 압축: [tinypng.com](https://tinypng.com)
